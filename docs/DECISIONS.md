# Decisions

Every significant decision and why. Source: design spec `docs/superpowers/specs/2026-11-03-portfolio-design.md` (the "[Claude's call]" items, section 9 and section 9b).

## 2026-11-03

- **Hacker mode lives at its own `/room` route.** A real URL can be shared directly and lets the 3D code load only when it is visited.
- **Stack: React + Vite single-page app, React Router, three.js via React Three Fiber, drei and postprocessing (bloom).** The owner already works in this stack and the old site used it.
- **3D code is lazy-loaded on `/room` only.** The formal page should never pay for three.js or the models.
- **Visual direction for formal mode: warm off-white, deep navy, UJ orange as a small accent, hairline borders, Plus Jakarta Sans with IBM Plex Mono labels.** Fits the owner's "close to Student, more young-professional" brief and stays inside the design bans.
- **Fonts self-hosted through @fontsource (OFL).** Licensed, no third-party font requests, no tracking.
- **Netlify Forms for the contact form.** No custom backend needed; it collects only name, email and message, with a honeypot and an unticked consent checkbox.
- **Cookie-free analytics (GoatCounter), no cookie banner.** No cookies and no tracking means no banner is required. If any cookie-setting tool is ever added, a consent banner becomes mandatory.
- **No terms or refund pages.** Nothing is sold, so both are not applicable.
- **No `server/` folder.** The site has no custom backend; `client/` holds the app and shared config sits at the root.
- **Lightweight client error logging (Sentry DSN via env, optional).** Covers the error-logging rule without a custom server.
- **Touch and fallback behaviour in the room.** Tappable on-screen controls for the terminal, plus a 2D terminal-only fallback when WebGL is unavailable or the frame rate stays very low.
- **Performance guards in the room.** Capped pixel ratio, throttled side-screen canvas redraws, rendering paused when the tab is hidden.
- **Phone number never appears on site pages; the Download CV button serves the full CV PDF with the phone number (owner's choice).** The PDF is the only place the number exists.
- **The fifth project is this portfolio, replacing Multi-Theme Developer Portfolio.** Described only by what is actually built; the owner plans to update the CV to match.
- **Availability line: "Open to roles, starting 2027".** Covers graduate roles, junior developer roles and internships.
- **Photo: plain head-and-shoulders 4:5 crop, no background removal.** Removes the camera watermark and most of the street background; an honest crop suits the tone. Exported as AVIF/WebP with a JPG fallback.
- **Old repo `Mukhodobwane_V` stays untouched on GitHub.** Rollback safety and history.
- **Deploy to a new Netlify preview site first; the owner relinks the existing site at launch via a handover checklist.** The live link stays the same and the owner controls the switch.
- **KSMS row has no links; Thusa Lushaka is named but not linked until its hosting move finishes.** No link is shown that may break or that the owner has not provided.
- **TryHackMe profile appears only in the room (`contact`, `whoami`), not on the formal page.** The CV does not list it.
- **Contact email is `mukhodobwanevhutali@gmail.com`, as on the CV.** Single source of truth for contact details.

## 2026-11-03: portrait crop and static assets

- **Final portrait crop: left 60, top 330, width 600, height 750 (4:5) from the 720x1280 original.** Checked visually: full head with headroom, shoulders framed, face in the upper third, "Galaxy S23+" watermark (y about 1215) excluded. No adjustment was needed. No background removal.
- **Outputs are 480 and 600 px wide (AVIF q50, WebP q75, JPG q80 mozjpeg).** 600 is the crop width, so nothing is upscaled; no 720 variant exists.
- **OG image and exports are generated by `npm run photo` (`scripts/process-photo.mjs`, sharp).** The OG image uses a generic sans-serif in the SVG because the renderer has no Plus Jakarta Sans.

## 2026-11-04: 3D room (Task 12)

- **Room models are refined primitives (rounded boxes, cylinders, tubes, instanced keycaps and rack LEDs); no external assets.** Nothing to license. Fonts on the screens are the self-hosted IBM Plex Mono (OFL), with the 700 weight imported only by the room chunk.
- **The 3D scene is its own lazy chunk inside the lazy Room page.** The formal entry has no three.js; the 2D fallback never downloads the scene. The scene chunk is ~1.06 MB minified (~290 kB gzip). `manualChunks` vendor splitting made the formal entry import the vendor chunk, so it stays one chunk and `chunkSizeWarningLimit` is 1100.
- **Low-FPS fallback: drei PerformanceMonitor, below 20 fps in most samples of two 2.5 s windows in a row.** Samples within 5 s of a tab becoming visible do not count. The fallback offers "Try the 3D room anyway", which turns the monitor off for the visit.
- **The 2D fallback skips the boot and fingerprint intro and opens on the menu.** It has no desk to sit at; the command line and buttons reuse the same engine. A "Text-only view" button in the HUD opens it by choice (also the screen-reader-friendly path).
- **Pose and terminal state live in one pure reducer (`roomReducer.js`).** A UI `sit` is a camera request; the engine hears `sit` when the camera reaches the chair, so the boot runs after the glide, as in the prototype.
- **Loading progress is real:** two steps (fonts ready, first frame rendered) reported through three's DefaultLoadingManager, so drei's `useProgress` shows 0 / 50 / 100 %.
- **Cans moved from x -1.25 to about -0.65 from the desk centre, and the chair hides while seated.** In the prototype the chair back hid the cans and they sat outside the seated view; on portrait screens the chair back covered the desk.
- **Bloom maps the prototype's UnrealBloom (0.75 / 0.55 / 0.55) to pmndrs Bloom with intensity 1.1, radius 0.55, threshold 0.55, mipmapBlur.** pmndrs intensity is weaker at the same number; 1.1 matched the prototype glow by eye. ACES tone mapping runs as the last effect.

## CSP style-src (Task 13 fix)

netlify.toml uses `style-src 'self'` with no `'unsafe-inline'`. A Playwright spec (tests/e2e/csp.spec.js) applies the exact header from netlify.toml to every document and fails on any `securitypolicyviolation` event or CSP console message across the formal page, contact submit, the 3D room and the no-WebGL fallback. It passed without `'unsafe-inline'`, because React and three.js set styles through the CSSOM, which CSP does not block. The `style-src-attr 'unsafe-inline'` fallback was therefore not needed. connect-src also lists the regional Sentry ingest hosts (de, us).
